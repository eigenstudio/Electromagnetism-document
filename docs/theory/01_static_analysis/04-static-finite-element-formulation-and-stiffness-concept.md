# Finite element formulation and stiffness concept

This theory chapter provides a short conceptual explanation for static analysis in ESD. It is intended to help users understand the meaning of the simulation inputs, solver behavior, and result quantities before using the related ESD screens.

## What does this chapter explain?

This chapter introduces the basic finite element idea used in static structural analysis. It explains how a continuous structure is divided into elements and nodes so that the response can be solved numerically.

## What is the stiffness concept?

Stiffness represents the resistance of a structure or element to deformation. In finite element analysis, the stiffness of all elements is assembled into a global system that relates applied loads to nodal displacements.

## What is solved in static analysis?

For a linear static problem, ESD solves the stiffness-based system where applied forces are balanced by internal structural resistance. The primary unknown is displacement.

## How does this chapter support ESD usage?

This chapter helps users understand why mesh quality, element type, material definition, and boundary conditions directly affect the accuracy of the computed results.

## What should users understand after this chapter?

After completing this chapter, users should be able to connect the theory concept with the corresponding ESD setup or result screen and use the concept to make better simulation decisions.
