# Result interpretation and common checks

This theory chapter provides a short conceptual explanation for static analysis in ESD. It is intended to help users understand the meaning of the simulation inputs, solver behavior, and result quantities before using the related ESD screens.

## What does this chapter explain?

This chapter explains how users should review and interpret static structural results in ESD.

## Why are result checks necessary?

A completed simulation does not automatically mean that the result is correct. Users must check whether the deformation pattern, stress distribution, and reaction forces are consistent with the expected physical behavior.

## What checks should users perform?

Users should check deformation scale, boundary condition behavior, load direction, reaction balance, mesh sensitivity, stress concentration regions, and whether maximum values occur at physically reasonable locations.

## What errors are commonly found?

Common issues include under-constrained models, incorrect load direction, unrealistic material properties, poor mesh quality, singularities near sharp corners, and interpreting local stress peaks without engineering judgment.

## What should users understand after this chapter?

After completing this chapter, users should be able to connect the theory concept with the corresponding ESD setup or result screen and use the concept to make better simulation decisions.
