# Introduction to static structural analysis

This theory chapter provides a short conceptual explanation for static analysis in ESD. It is intended to help users understand the meaning of the simulation inputs, solver behavior, and result quantities before using the related ESD screens.

## What does this chapter explain?

This chapter introduces the basic meaning of static structural analysis in ESD. It explains how a structure responds when loads are applied steadily and the response is evaluated under static equilibrium conditions.

## Why is static analysis important?

Static analysis is one of the most common structural simulation workflows. It helps users estimate deformation, stress, strain, and reaction forces when inertia and time-dependent effects are not significant.

## What concepts are introduced?

Users are introduced to equilibrium, steady loading, support conditions, stiffness, displacement, and the general relationship between the applied load and structural response.

## How does this chapter support ESD usage?

This chapter prepares users to understand what ESD is solving during a static simulation and why the correct definition of geometry, material, loads, and constraints is important.

## What should users understand after this chapter?

After completing this chapter, users should be able to connect the theory concept with the corresponding ESD setup or result screen and use the concept to make better simulation decisions.
