# Loads, constraints, and equilibrium

This theory chapter provides a short conceptual explanation for static analysis in ESD. It is intended to help users understand the meaning of the simulation inputs, solver behavior, and result quantities before using the related ESD screens.

## What does this chapter explain?

This chapter explains how loads and constraints define a static structural problem. It introduces the role of forces, pressure, moments, fixed supports, displacement constraints, and other boundary conditions.

## Why are loads and constraints important?

Loads describe what is acting on the structure, while constraints describe how the structure is supported or restricted. Together, they determine whether the problem is physically meaningful and solvable.

## What is static equilibrium?

Static equilibrium means that the applied loads and support reactions are balanced. In finite element analysis, this balance is represented through the structural stiffness equation solved by ESD.

## What should users check?

Users should check whether the model is sufficiently constrained, whether load directions are correct, and whether the selected faces, edges, or nodes represent the intended physical setup.

## What should users understand after this chapter?

After completing this chapter, users should be able to connect the theory concept with the corresponding ESD setup or result screen and use the concept to make better simulation decisions.
