# Theory Manual: eigenspacedesign

## What is covered in the theory section?

The theory section introduces the engineering and finite element concepts required to understand the static and dynamic structural analysis workflows available in ESD. This section is intended to give users the background needed to make sense of the software inputs, solver settings, and result quantities shown in the ESD interface.

This section is organized into two main chapters:

- Static analysis
- Dynamic analysis

The theory pages explain the concepts behind the screens and settings used in ESD. They are not written as software tutorials, but as supporting references for users who want to understand why certain inputs are required and how the results should be interpreted.

## How is the theory section organized?

The theory section is organized into two main chapters: static analysis theory and dynamic analysis theory.

The static analysis theory chapter explains the basic assumptions and governing ideas behind static structural finite element analysis. It introduces the relationship between loads, constraints, stiffness, displacement, strain, stress, and reaction forces.

The dynamic analysis theory chapter explains the concepts required to understand structural response under time-dependent, inertial, or vibration-related loading. It introduces the role of mass, damping, stiffness, natural frequencies, mode shapes, and time-dependent response.

Together, these chapters provide the theoretical foundation needed to understand how ESD performs structural finite element analysis and how users should interpret the results produced by static and dynamic simulations.


## What should users learn from this section?

After completing the theory section, users should understand the basic concepts behind the inputs and results used in ESD structural simulations. The section should help users make better decisions while defining materials, loads, constraints, mesh settings, solver controls, and result views.

The theory section also prepares users to understand the practice and validation sections more clearly by explaining the engineering meaning behind the software workflow.

## How should users use this section?

Users can read the theory section before starting the practice problems, or refer to it whenever a specific input or result quantity needs clarification. The static analysis theory chapter should be reviewed before static simulations, while the dynamic analysis theory chapter should be reviewed before dynamic simulations.
