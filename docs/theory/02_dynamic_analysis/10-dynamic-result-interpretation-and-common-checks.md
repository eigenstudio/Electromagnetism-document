# Dynamic result interpretation and common checks

This theory chapter provides a short conceptual explanation for dynamic analysis in ESD. It is intended to help users understand the meaning of the simulation inputs, solver behavior, and result quantities before using the related ESD screens.

## What does this chapter explain?

This chapter explains how users should review and interpret results from dynamic simulations in ESD.

## What results are commonly reviewed?

Dynamic analysis may produce natural frequencies, mode shapes, displacement-time curves, velocity, acceleration, stress variation, frequency response curves, and response amplitudes.

## What checks should users perform?

Users should check time step adequacy, frequency range, damping assumptions, excitation direction, boundary conditions, mode shape reasonableness, and whether the response trends are physically consistent.

## What errors are commonly found?

Common issues include missing density, incorrect damping, insufficient time resolution, unrealistic constraints, ignored rigid body modes, and misinterpreting scaled mode shapes as actual displacement magnitudes.

## What should users understand after this chapter?

After completing this chapter, users should be able to connect the theory concept with the corresponding ESD setup or result screen and use the concept to make better simulation decisions.
