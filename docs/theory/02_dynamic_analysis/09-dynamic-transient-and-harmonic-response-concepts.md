# Transient and harmonic response concepts

This theory chapter provides a short conceptual explanation for dynamic analysis in ESD. It is intended to help users understand the meaning of the simulation inputs, solver behavior, and result quantities before using the related ESD screens.

## What does this chapter explain?

This chapter introduces two common dynamic simulation concepts: transient response and harmonic response.

## What is transient response?

Transient response describes how a structure responds over time when subjected to loads such as a step, pulse, impact-like excitation, or any time-varying input.

## What is harmonic response?

Harmonic response describes how a structure responds to sinusoidal loading over a range of excitation frequencies. It is commonly used to identify resonance and vibration amplification.

## What should users understand?

Users should understand the difference between time-domain and frequency-domain response, and how solver controls such as time step, duration, frequency range, and damping affect the results.

## What should users understand after this chapter?

After completing this chapter, users should be able to connect the theory concept with the corresponding ESD setup or result screen and use the concept to make better simulation decisions.
