# Natural frequency and mode shapes

This theory chapter provides a short conceptual explanation for dynamic analysis in ESD. It is intended to help users understand the meaning of the simulation inputs, solver behavior, and result quantities before using the related ESD screens.

## What does this chapter explain?

This chapter explains free vibration, natural frequency, and mode shapes. These concepts are central to modal analysis in ESD.

## What is natural frequency?

Natural frequency is the frequency at which a structure tends to vibrate when disturbed without continuous external forcing.

## What are mode shapes?

Mode shapes describe the deformation patterns associated with each natural frequency. They show how different parts of the structure move relative to each other during vibration.

## What should users check?

Users should check for rigid body modes, unrealistic constraints, unexpected mode shapes, and whether the frequency range is suitable for the intended engineering use.

## What should users understand after this chapter?

After completing this chapter, users should be able to connect the theory concept with the corresponding ESD setup or result screen and use the concept to make better simulation decisions.
