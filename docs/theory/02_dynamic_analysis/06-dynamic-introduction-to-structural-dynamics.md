# Introduction to structural dynamics

This theory chapter provides a short conceptual explanation for dynamic analysis in ESD. It is intended to help users understand the meaning of the simulation inputs, solver behavior, and result quantities before using the related ESD screens.

## What does this chapter explain?

This chapter introduces the basic idea of structural dynamics in ESD. It explains how structural response changes when loads vary with time, frequency, or vibration.

## How is dynamic analysis different from static analysis?

Static analysis considers equilibrium under steady loads, while dynamic analysis includes the effects of mass, inertia, damping, and time-dependent or frequency-dependent excitation.

## When is dynamic analysis required?

Dynamic analysis is required when the loading changes rapidly, when vibration is important, or when the response depends on natural frequencies, mode shapes, or transient motion.

## How does this chapter support ESD usage?

This chapter prepares users to understand why dynamic simulations require additional inputs such as density, damping, time step, frequency range, or modal extraction settings.

## What should users understand after this chapter?

After completing this chapter, users should be able to connect the theory concept with the corresponding ESD setup or result screen and use the concept to make better simulation decisions.
